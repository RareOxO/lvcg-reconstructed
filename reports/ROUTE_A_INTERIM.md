## 2. 问题

### 2.1 A2 的扰动过强，无法区分敏感性

三种扰动都把 AUROC 从约 88 打到 **61–67**（下降 21–26 pp），`e_base` 的相对位移接近
**1.0**——意味着打乱顺序后，冻结主干看到的已经是一条**完全不同的轨迹**，而不是
"同样的旋转、不同的顺序"。

方案 A2 要验证的是"proposed representation 是否对有序 3D rotational evolution **更敏感**"。
在两个模型都崩溃的破坏程度下，这个比较没有意义：观察到的 loop 比 v0 高 3–4 pp，
更可能反映的是"loop 的分类器在废轨迹上仍能抓住一点残余信息"，而不是敏感性差异。

**实现本身是正确的**：单元测试验证了每步转角的多重集逐位保持（1e-3）、幅度剖面保持
（1e-4）、扰动确定可复现。问题出在**扰动强度的选择**——把 127 步做全排列，在物理上
等于把心拍轨迹重画一遍。方案只要求"保持 rotation amount 分布尽可能不变"，没有要求
保持轨迹整体形状，这是我设计时的判断失误。

### 2.2 已有的一个正面线索

`block`（块长 8）的破坏明显轻于 `shuffle`（v0 掉 21.29 vs 26.29）。这说明
**扰动强度是可以调节的**，梯度化的敏感性曲线是可行的。

### 2.3 A1 结论的适用范围

A1 的比较全部在 `struct=mean` 下完成，与 V1–V8 的 anchor 基线不可直接相加。
`loop` 的 +0.75 也明显小于 V3 的 `mo` 在同类位置的增量，但两者基线不同，
需要在统一基线下复核后才能横向比较。

## 3. 结论

**A1：不支持。** 多尺度有序合成相对单步四元数只有 +0.05 pp，落在方案 A3 的
"composition 与 local QDF 无明显区别"这一档。**有序合成本身不是缺失的那块信息**——
这与 V3 的结论一致：旋转信息在绝对方向已知时是冗余的，换成"合成起来的旋转"也不改变
这一点。

**A2：设计失败，需重做，因此 A3 的自动决策不能下。** 按方案 A3，"不支持"这一档要求
**clean 提升小 且 signature test 也不成立**；目前 signature test 无效，所以不能宣布
该路线停止。

**下一步（唯一必要的一步）**：把扰动强度做成扫描——块长 2 / 4 / 8 / 16 / 32 / 127，
块越小破坏越轻——观察两个模型的 AUROC 衰减曲线在**轻度扰动区**是否分开。
改动是脚本加一个 `--block-sizes` 参数，一次运行约 5 分钟。

- 若轻度扰动下 `loop` 的衰减明显小于/大于 `v0`：signature test 成立，按 A3 的
  "部分支持"分支走（clean 提升小但 signature 强 → 转 low-label / lead sparsity 验证）。
- 若两条曲线在所有强度下都重合：A3 的"不支持"成立，停止路线 A，不再加深四元数网络。

**另一件应当独立执行的事**：把 `struct=mean` 作为新的 V0 基线写入 experiment registry，
并在后续所有路线中使用。这与四元数无关，但它是本批实验中最大的单项增量（+1.61 pp）。
