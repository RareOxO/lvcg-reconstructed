# V3 — MRQ-LVCG（V1 结果驱动的修订版），Tier 1 报告

**阶段**：Stage A + Stage B 全部完成 | **协议**：Tier 1，冻结主干，V1 架构不变
**日期**：2026-09-18 | **运行**：9 个变体 × 3 seed = 27 次
**结论**：**几何分解成立（H3.1、H3.2、H3.4 支持），四元数旋转不成立（H3.3、H3.5 不支持）**

---

## 1. Executive Summary

把潜在心向量显式拆成"幅度 × 绝对方向"（`mo`）达到 **89.55 ±0.03**，**高于未分解的
Cartesian 参考 `cdf` 的 89.33 ±0.10**，相对 V0 提升 +4.27 pp。分解本身因此是有效的，
甚至优于直接喂 Cartesian 轨迹。

但相对旋转 q_t 在任何已有方向信息的组合中都是负贡献：`o → oq` 掉 0.59，`mo → moq`
掉 0.56。四条配对比较（q<o、mq<mo、oq<o、moq<mo）方向完全一致，因此本阶段
**不支持 Quaternion-specific benefit**。

V1 的核心疑问得到解答：`mq`（V1 的 QDF）落后 `cdf` 1.33 pp，**主因确实是缺失绝对方向**——
仅用方向的 `o` 就把差距缩到 0.58 pp，而补上幅度的 `mo` 则反超。

## 2. Research Question 与预注册假设的判定

| 假设 | 内容 | 判定 | 依据 |
|---|---|---|---|
| H3.1 | M、O、Q 中至少一类在 e_base 之外有稳定增量 | **支持** | 三者单独均高于 V0：+1.37 / +3.47 / +2.01 |
| H3.2 | CDF > QDF 主因是 QDF 丢失 absolute orientation | **支持** | `oq − q` = +0.87；`o` 与 cdf 差距仅 −0.58（mq 为 −1.33） |
| H3.3 | relative rotation 与 absolute orientation 互补 | **不支持** | `oq`（88.16）低于 `o`（88.75）0.59 pp，σ 仅 0.06 / 0.16 |
| H3.4 | M+O+Q 接近或超过 CDF | **支持** | `moq` −0.34；不含 Q 的 `mo` **+0.22**，即分解可重构并略超 Cartesian |
| H3.5 | 存在 Quaternion-specific benefit | **不支持** | 四组配对全部为负（见第 12 节） |

## 3. Pretrained Initialization 与等价性

| 项 | 值 |
|---|---|
| checkpoint | `checkpoints/m5fasts1k1/final.pt`（500,000 步 MIMIC SSL） |
| frozen | 主干 8,285,060 参数全部 `requires_grad=False` |
| trainable | 一个 `DynamicEncoder` + 线性头 |
| 缓存 | 与 V1 共用同一份 `e_base` [N,640] 与 VCG [N,3,1000] |

**三项交叉验证通过**（方案 11 节要求 V1 结果作为 locked reference）：

| 变体 | V1 锁定值 | V3 本次 | 差 |
|---|---:|---:|---:|
| v0 | 85.28 ±0.04 | 85.28 ±0.04 | 0.00 |
| mq（= V1 的 QDF） | 88.00 ±0.07 | 88.00 ±0.07 | 0.00 |
| cdf（= V1 的 control） | 89.33 ±0.10 | 89.33 ±0.10 | 0.00 |

单元测试另外验证了 `mq` 与 V1 实现**逐通道相同、同种子下 logits 逐位相等**，
`cdf` 通道集亦然。`q` 本次为 3 seed 的 87.29 ±0.15，V1 的单 seed 值 87.49 落在其上沿。

## 4. V0-equivalence Check（方案 7 / Level 0）

`logits = Linear([e_base ; scale · e_G])`，`v0` 变体的 `scale = 0`。单元测试验证输出与
"仅 e_base 的线性探针"**逐位相等**，且分支权重梯度恒为 0；`scale = 1` 时各变体分支
均收到非零梯度。

## 5. Feature Definitions（方案 4 节）

| 符号 | 通道 | 数 | 几何含义 |
|---|---|---:|---|
| M | r_t = ‖P_t‖ | 1 | 心向量强度 |
| O | u_t = P_t / ‖P_t‖ | 3 | 固定潜空间坐标系中的绝对方向 |
| Q | q_t, θ_t, ω_t | 6 | u_t → u_{t+1} 的相对转动 |
| CDF | P_t, P_{t+1}, ΔP_t | 9 | 未分解的 Cartesian 参考 |

所有集合额外附带 1 个可靠性 mask 通道。通道顺序在全局统一为"旋转 → 幅度 → 方向"，
即 V1 的顺序，因此 `mq` 与 V1 逐通道一致。

**数值与几何要求的落实**：`u_t` 在固定潜空间坐标系计算，**不做 sample-wise 旋转归一化**
（单元测试验证旋转整条记录会改变 u_t，即绝对方向未被消除）；低于记录 99 分位幅度 2%
的 transition 被 mask 且填入 identity 四元数；反平行使用确定性 fallback；沿时间强制
符号连续；θ = 2·atan2(‖q_xyz‖, |q_w|)，ω = θ/Δt，不使用 Euler 角；幅度经编码器首层
BatchNorm 标准化，所有含 M 的集合共享同一变换。

## 6. Architecture（方案 6 节：只改特征，不改结构）

```
ECG → frozen LVCG → { e_base [B,640] , VCG P [B,3,1000] }
P → FeatureExtractor(变体通道) → DynamicEncoder(3×stride-2 conv, masked pooling) → e_G [B,128]
logits = Linear([ e_base ; scale · e_G ]) → [B,5]
```

backbone、编码器、池化、dropout、分类器协议与 V1 完全一致；变体之间**只有输入通道不同**。

## 8. 增量分析：每一类信息各值多少

把每个变体看作"在某个基底上加入一类信息"，可以直接读出边际贡献：

| 加入 | 基底 → 结果 | 边际 |
|---|---|---:|
| **加 O** | m → mo | **+2.91** |
| | q → oq | +0.87 |
| | mq → moq | +0.99 |
| **加 M** | o → mo | +0.80 |
| | q → mq | +0.71 |
| | oq → moq | +0.83 |
| **加 Q** | m → mq | **+1.36** |
| | o → oq | **−0.59** |
| | mo → moq | **−0.56** |

三点结论：

1. **O 是最大的单一贡献者**，且在没有方向信息时边际最大（+2.91）。
2. **M 的边际非常稳定**（+0.71 / +0.80 / +0.83），是真正独立于方向的信息——符合几何直觉，
   幅度与方向是正交的两个自由度。
3. **Q 的边际取决于方向是否已在场**：只有 M 时加 Q 有 +1.36，一旦有了 O 就变成 −0.6 左右。
   这正是"q_t 是方向信息的有损函数"的表现：它能替代一部分方向信息，但在方向已知时
   只剩冗余，反而稀释了通道。

**可加性**：m 单独 +1.37、o 单独 +3.47，合计 4.84，而 mo 实际 +4.27，次可加 0.57，
说明两者有小幅重叠但绝大部分互补。

## 9. Per-label Results（test AUROC，seed 42）

| 变体 | NORM | MI | STTC | CD | HYP |
|---|---:|---:|---:|---:|---:|
| v0 | 0.8982 | 0.8397 | 0.8869 | 0.8556 | 0.7819 |
| m | 0.9093 | 0.8623 | 0.8962 | 0.8740 | 0.8065 |
| q | 0.9153 | 0.8767 | 0.9038 | 0.8746 | 0.8043 |
| mq | 0.9212 | 0.8875 | 0.9043 | 0.8832 | 0.8033 |
| oq | 0.9228 | 0.8928 | 0.9173 | 0.8877 | 0.7977 |
| o | 0.9245 | 0.9006 | 0.9206 | 0.8865 | 0.8016 |
| moq | 0.9247 | 0.9029 | 0.9213 | 0.8948 | 0.8071 |
| cdf | **0.9296** | **0.9094** | 0.9242 | **0.9036** | 0.7984 |
| **mo** | **0.9304** | 0.9041 | **0.9261** | 0.9028 | **0.8119** |

**mo 为何能超过 cdf**：两者在 NORM / STTC / CD 上几乎持平（±0.3 pp），差别集中在
**HYP：0.8119 vs 0.7984（+1.35 pp）**。HYP（心室肥大）是最依赖振幅判据的诊断
（Sokolow-Lyon 等都是电压标准），而 `mo` 有一条专门的幅度通道，`cdf` 的幅度信息则
混在三个 Cartesian 分量里。相应地，cdf 在 MI（0.9094 vs 0.9041）上略胜，MI 更依赖
逐点形态。**显式分解的价值因此是可解释的，而非拟合噪声。**

另外注意 **HYP 是唯一 `m` 单独就接近最好水平的 label**（0.8065，仅次于 mo 的 0.8119，
高于 cdf），进一步印证幅度通道对该 label 的作用。

## 10. Training Curve 与稳定性

- 所有变体 5–17 个 epoch 内早停，无发散。
- **v0 收敛最慢（17.0 epoch）**：线性探针只有 3,205 个参数；加入分支后 5–12 epoch 即触发早停。
- **m 的 σ 最大（0.33）且 epoch 最长（12.3）**：单通道输入信息量最少，优化路径最不稳定。
- **mo 的 σ 最小（0.03）**：信息最充分的非冗余组合，三个 seed 几乎一致。
- 含 Q 的组合 σ 普遍略大（0.06–0.16）。

## 11. Parameter / 容量控制

方案第 7 节禁止为让四元数更强而扩大其 encoder。本报告全部变体共用同一 encoder 配置
（hidden 64，embedding 128，kernel 7，3 层 stride-2），参数差异仅来自输入通道数，
极差 2.3%，且**参数最多的 `moq`（182,043）并非最佳，参数较少的 `mo`（179,343）最佳**——
容量方向与结果方向相反，排除了"容量解释"。

## 12. Quaternion-specific Benefit 的判定（方案 9 节规则）

方案明确禁止"只要高于 V0 就算成功"。逐对比较含 Q 与其匹配的不含 Q 版本：

| 含 Q | 不含 Q 的对照 | 差 |
|---|---|---:|
| q 87.29 | o 88.75 | **−1.46** |
| mq 88.00 | mo 89.55 | **−1.55** |
| oq 88.16 | o 88.75 | **−0.59** |
| moq 88.99 | mo 89.55 | **−0.56** |

四组全部为负，且均超过各自的 σ。**Quaternion-specific benefit 不成立。**

需要与 H3.1 区分清楚：q 单独确实高于 V0（+2.01），即相对旋转**含有** e_base 之外的信息；
但它所含的信息是绝对方向信息的子集/有损版本，因此在任何已包含方向的表示中都是冗余。

## 13. 替代解释与已排除项

- **容量**：已排除（第 11 节，最佳变体参数并非最多）。
- **seed 噪声**：已排除。σ 为 0.03–0.33，而被讨论的差值为 0.56–1.55 pp，且逐 seed 配对一致。
- **通道数偏置**（O 有 3 通道、Q 有 6 通道）：如果通道多就更好，Q 应占优，实际相反。
- **编码器不适配四元数**：仍是可能的残余解释——BatchNorm + 1D 卷积是为实值时序设计的。
  但方案要求结构一致，这是公平性与最优性之间的必然取舍；且 `q` 单独已能取得 +2.01，
  说明编码器并非无法利用四元数通道。
- **尚未检验的方向**：本实验只测精度，未测**旋转鲁棒性**。四元数的理论优势在于对整体
  旋转不变，而 `o` 恰恰对旋转敏感——这是四元数主张仍可能成立的唯一位置（见第 15 节）。

## 14. Stage Conclusion

**Gate A（Stage A）通过**：`oq − q` = +0.87 且 `q → cdf` 差距由 −2.04 缩至 −1.17，
absolute-orientation hypothesis 获得支持，因此进入 Stage B（已完成）。

**Gate B（Stage B）**：`moq − cdf` = −0.34（接近），且不含 Q 的 `mo` 超过 cdf（+0.22）。
按方案，"完整显式几何分解可重构 Cartesian 轨迹的有效信息"成立。

**V3 总判定**：
- **几何分解实验：成功**。latent VCG 的诊断信息可以分解为幅度与绝对方向，二者互补，
  显式分解不劣于（且在 HYP 上优于）未分解的 Cartesian 表示。
- **四元数假设：不支持**。相对旋转在方向已知时为冗余，四条配对比较一致为负。

## 15. Next Experiment Recommendation

1. **不进入 Tier 2**：Tier 1 未显示可归因的 quaternion geometric advantage，方案第 10 节
   的前提未满足。
2. **四元数主张唯一剩余的检验位置是旋转鲁棒性**（方案 6.3）：对测试记录施加
   [0, 5, 10, 30, 60, 90, 150] 度的整体旋转，比较 `o`、`mo`、`q`、`oq`、`cdf` 的 AUROC 衰减。
   预期 `o`/`mo`/`cdf` 明显退化而 `q` 基本不变——若成立，四元数的价值应重新定位为
   **不变性**而非精度，这是一个诚实且有意义的结论，也直接衔接 V5（canonicalization）
   与 V6（adaptive lead geometry）。**这是我建议的下一步。**
3. **`mo` 超过 `cdf` 值得单独确认**：差距仅 +0.22 pp，建议补 seeds 45/46 以确认，
   并在报告中保持"略优/持平"的措辞，不宜强调。
4. **对后续版本的影响**：V5/V6 应把 `mo`（89.55）而非 `mq` 作为新的强基线；
   任何新方法若不能超过 `mo`，就不能声称几何建模上的进步。
