# V5 — QC-LVCG，Tier 1 报告（位姿正则化 + 旋转鲁棒性）

**阶段**：Stage 7（方案顺序）| **协议**：Tier 1，冻结主干，identity-init 位姿
**日期**：2026-09-18 | **运行**：7 个配置，**seed 42 单 seed**（v0 与 canon 另有一批 3 seed 记录）
**结论**：**MIXED —— 精度有稳定但很小的增量（约 +0.5 pp）；单靠正则化得不到旋转不变性；
位姿估计在旋转增强之上确有额外贡献**

---

## 1. Executive Summary

把每条记录的全局朝向估计出来并消掉，使冻结的预训练模型总是看到同一姿态下的轨迹。
干净数据上带来 **+0.32 至 +0.57 pp** 的提升，四种约束配置结果几乎相同，说明这是一个
真实但有限的增益。

**旋转鲁棒性上结论分两半**：只在未旋转数据上训练时，正则化**反而更脆弱**
（60° 衰减 13.8 pp，而 V0 是 11.1 pp）——位姿头从没学过如何估计被旋转记录的姿态。
一旦训练时见到旋转，`canon+augment` 在**每一个角度**都优于纯 `augment` 对照
（30° +1.45、60° +2.53、90° +3.28 pp），这正是方案要求区分的那一点：
**不变性不只是"见过旋转"，位姿估计本身有贡献**。

| 配置 | 0° | vs V0 | 位姿角 中位/p90/max | 60° 衰减 | 90° 衰减 |
|---|---:|---:|---|---:|---:|
| v0（冻结路径） | 85.75 | — | — | −11.11 | −20.39 |
| canon（≤30°） | 86.07 | +0.32 | 27.7 / 29.7 / 30.0 | −13.78 | −23.87 |
| canon ≤10° | 86.27 | +0.52 | 10.0 / 10.0 / 10.0 | −13.40 | −23.19 |

| augment（对照） | 81.63 | −4.12 | — | **−2.95** | **−5.14** |
| **canon + augment** | 82.36 | −3.39 | 30.0 / 30.0 / 30.0 | **−1.15** | **−2.60** |

## 2. Research Question 与假设判定

**问题**（方案 2 表 V5 行）：global orientation 这个 nuisance 是否值得 canonicalize？

| 假设 | 判定 | 依据 |
|---|---|---|
| 消除全局朝向能提升干净数据上的精度 | **弱支持** | +0.32 至 +0.57 pp，四种配置一致，但幅度小 |
| 正则化本身带来旋转不变性 | **不支持** | 不带增强时 60° 衰减 13.8 vs V0 的 11.1，更差 |
| 位姿估计的价值可与单纯旋转增强区分 | **支持** | `canon+aug` 在全部 7 个角度上优于 `augment` |
| 位姿头学到的是逐记录的姿态而非固定变换 | **支持（需约束）** | 加 identity 惩罚后角度分布分散（中位 3.4°、max 21.1°）且精度不降 |

## 3. Pretrained Initialization 与等价性

| 项 | 值 |
|---|---|
| checkpoint | `checkpoints/m5fasts1k1/final.pt` |
| frozen | 心拍编码器、StateGRU、norm_struct、norm_dynamic（可微但不更新） |
| trainable | 位姿头 44,489 + 线性头 3,205 = **47,694**（全部阶段中最少） |
| 缓存 | 复用 V2 的心拍 patch，**无需重跑冻结前向** |

**四项检查通过**：

1. **V0 = 85.75**，与 V2 的 85.67 ±0.03 一致（同为"重放冻结路径 + 逐记录 GRU 展开"）。
2. **identity 初始化**：位姿头末层零初始化 ⇒ `q_pose = [1,0,0,0]` 精确成立；
   单元测试验证此时输出与"无位姿头"路径**逐位相等**，初始校正角 < 1e-4 度。
3. **旋转与分段可交换**：单元测试用真实分段器验证（误差 < 1e-5），这是"可以直接旋转
   缓存心拍"的前提。
4. **固定位姿可精确抵消已知旋转**：把位姿头钉在 r 上，被 R(r) 旋转的记录回到原位（1e-4）。

## 4. 方法

```
q_pose = PoseNet(V_obs)                    # 轴角向量，末层零初始化，tanh 限幅
V_c    = R(q_pose)^T · V_obs               # 逐记录消除全局朝向
logits = Linear( 冻结LVCG(V_c) )            # 心拍编码器 → GRU → norms（全部冻结但可微）
```

- **`max_degrees`**：tanh 软约束，防止未训练的位姿头把输入推出主干熟悉的分布。
- **`identity_weight`**：方案提到的 identity prior，对校正角施加 `(θ/180°)²` 惩罚。
- **`--model augment`**：不带位姿头、但用完全相同的随机旋转批次训练——方案第 4 节要求的
  "必须与单纯 rotation augmentation control 区分"。
- **旋转扫描**（方案 6.3）：测试时对每条记录施加固定角度、随机轴的旋转，角度取
  0 / 5 / 10 / 30 / 60 / 90 / 150 度。

## 5. 详细分析

### 5.1 增益很小，且与约束方式无关

四种配置——无约束（≤30°）、≤10°、prior 1.0、prior 10.0——分别是 +0.32 / +0.52 / +0.57 /
+0.50 pp，彼此差异小于 seed 波动（v0 与 canon 的另一批 3 seed 记录显示 canon 在
85.99–86.56 之间浮动）。**怎么约束都一样，说明增益不取决于旋转的幅度。**

### 5.2 "只学了一个固定变换"这一怀疑被证伪

无约束时位姿角顶满上限（中位 27.7°，上限 30°），换成 10° 上限后依然顶满（中位 10.0°）——
看起来像是学了一个对所有记录都相同的旋转。但加上 identity 惩罚后：

| 惩罚权重 | 中位 | p90 | max | 0° AUROC |
|---|---:|---:|---:|---:|
| 0（≤30°） | 27.7 | 29.7 | 30.0 | 86.07 |
| 1.0 | 10.9 | 21.5 | 28.3 | 86.32 |
| 10.0 | **3.4** | **7.7** | **21.1** | 86.25 |

角度分布**出现了真正的个体差异**（prior 10 下中位 3.4° 而最大仍有 21.1°），
**而精度不降反升**。因此：顶满上限只是一个未被约束的自由度，真正起作用的是
**小幅、逐记录的校正**；旋转角的大小本身对结果几乎无关。

这也给出实践建议：**若要使用 V5，应带 identity prior**——同样的精度，校正角小一个量级，
对预训练输入分布的扰动最小，解释也最贴近"canonicalization"。

### 5.3 不带增强时，正则化反而更脆弱

| 角度 | v0 | canon |
|---|---:|---:|
| 10° | −0.32 | −0.35 |
| 30° | −3.51 | −4.28 |
| 60° | −11.11 | **−13.78** |
| 90° | −20.39 | **−23.87** |

位姿头只在未旋转的数据上训练，因此从未学过"一条被旋转 60° 的记录应该转回来"。
测试时它给出的是错误的校正，误差叠加在原有的旋转敏感性之上。
**正则化不会自动带来不变性，除非训练分布里有旋转。**

### 5.4 关键对照：位姿估计在增强之上确有贡献

| 角度 | augment | canon + augment | 差 |
|---|---:|---:|---:|
| 0° | 81.63 | 82.36 | **+0.73** |
| 10° | 81.46 | 82.29 | +0.83 |
| 30° | 80.80 | 82.25 | **+1.45** |
| 60° | 78.68 | 81.21 | **+2.53** |
| 90° | 76.48 | 79.76 | **+3.28** |
| 150° | 72.14 | 72.25 | +0.11 |

七个角度全部为正，且**角度越大优势越明显**（0° → 90° 从 +0.73 升到 +3.28），
这正是"位姿被估计并消除"应有的表现。150° 处优势消失，可能与轴角表示在接近 π 时的
歧义有关（此时旋转的正负方向难以区分）。

按方案第 4 节"任何增益必须与单纯 rotation augmentation control 区分"的要求，
**这一条是 V5 唯一明确成立的正面结果。**

### 5.5 代价：干净数据上掉 3.4 pp

`canon+augment` 在 0° 只有 82.36，比 v0 低 3.39 pp。旋转增强让模型在全朝向下都能用，
代价是牺牲了针对真实电极朝向分布的特化。**这是一个取舍，不是改进**：
除非部署场景真的会遇到大角度朝向变化，否则 v0/canon 更合适。

### 5.6 冻结的 LVCG 本身对旋转极不鲁棒

一个独立于 V5 的事实：V0 在 90° 掉 20.4 pp，150° 掉到 52.27——接近随机。
**预训练表示完全没有旋转不变性**，这说明 V5 针对的 nuisance 是真实存在的，
只是当前方法在不改变训练分布的前提下解决不了它。

### 5.7 per-label（seed 42）

| 配置 | NORM | MI | STTC | CD | HYP |
|---|---:|---:|---:|---:|---:|
| v0 | 0.9028 | 0.8492 | 0.8899 | 0.8588 | 0.7869 |
| canon | 0.9052 | 0.8616 | **0.9017** | 0.8496 | 0.7855 |
| canon ≤10° | 0.9060 | 0.8673 | 0.8925 | 0.8605 | 0.7873 |
| canon prior1 | **0.9063** | **0.8679** | 0.8967 | 0.8558 | **0.7893** |
| augment | 0.8549 | 0.7944 | 0.8419 | 0.8292 | 0.7608 |
| canon + augment | 0.8695 | 0.8055 | 0.8565 | 0.8210 | 0.7657 |

canon 的收益集中在 **MI（+1.2 至 +1.9 pp）与 STTC（+0.3 至 +1.2 pp）**，CD 与 HYP 基本不动
甚至略降。MI 与 STTC 依赖 ST-T 形态在空间中的朝向，与"消除全局朝向后形态更可比"这一
机制自洽。旋转增强则在所有 label 上一致降低，MI 掉得最多（−5.5 pp）。

## 6. Numerical Sanity Checks

20 个单元测试通过：零轴角精确给出单位四元数；轴角按指定轴与角度旋转；随机旋转矩阵
满足 `RᵀR = I`、`det R = 1` 且角度精确；**旋转与心拍分段可交换**；旋转后的心拍是连续内存
（预训练编码器用 `view`）；位姿在初始化时精确为 identity；`max_degrees` 限幅生效；
位姿主要读取有效心拍（补齐心拍的影响小 3 倍以上）；identity 位姿下与冻结路径逐位相等；
固定位姿精确抵消对应旋转；无位姿头时旋转确实改变输出（nuisance 真实存在）；
只有位姿头与线性头可训练；梯度穿过冻结模型到达位姿头；冻结 GRU 关闭 dropout 并跟随
probe 模式（cuDNN 要求）；7 个角度的扫描全部输出有限值。

## 7. Stage Conclusion

**MIXED**：

- **精度**：+0.5 pp 左右，稳定但小；四种约束方式无差别。
- **不变性**：单靠正则化不成立（反而更差）；需要训练时见到旋转。
- **位姿估计的独立价值**：成立——在相同的旋转增强下，带位姿估计比不带好 0.7 至 3.3 pp，
  且角度越大优势越大。
- **可解释性**：加 identity prior 后位姿角呈现个体差异且精度不降，支持
  "逐记录姿态校正"的解释，否定"固定输入变换"的怀疑。

**证据强度限制**：除 v0 与 canon 外均为**单 seed（42）**。canon 在另一批 3 seed 中波动
0.5 pp，因此 +0.5 pp 的精度增益**不宜作为定论**；5.4 节的对照差值（最大 3.3 pp）
明显大于该波动，结论相对更稳。

## 8. Next Experiment Recommendation

1. **若要确认 5.4 节的结论**，补 `augment` 与 `canon+augment` 的 seed 43/44（6 次运行，
   约 8 分钟）。这是本阶段唯一值得补的实验。
2. **默认配置建议改为 `identity_weight: 1.0`**：同样精度，校正角更小更可解释。
3. **V6（自适应导联几何）应当直接受益于本阶段的两个发现**：
   （a）预训练表示完全没有旋转不变性，几何校正的空间是真实的；
   （b）几何校正必须在训练分布中包含相应变化才能学会，否则只会学到一个常数偏移。
4. **不进入 Tier 2**：Tier 1 的精度增益太小，且与四元数表示本身无关（位姿可以用任何
   3 参数旋转表示实现）。
