# Quaternion-LVCG 全线总结（V0–V8）

**日期**：2026-09-18 | **协议**：Pretrained-first，Tier 1 全程冻结主干，PTB-XL Super-class
**基线**：`checkpoints/m5fasts1k1/final.pt`（MIMIC-IV-ECG 500,000 步 SSL）
**总结论**：**没有任何阶段证明四元数表示本身有独立价值；真正有效的是"重新读取潜在 VCG
轨迹"这件事，而在所有被测表示中，幅度 + 绝对方向（`mo`）最好。**

## 2. 四条主结论

### 2.1 四元数表示没有被证明有独立价值

方案第 9 节明确规定：**Quaternion-specific claim 必须建立在参数匹配的对照之上**，
仅仅高于 V0 不算数。按此标准，每一次对照都是负的：

| 比较 | 阶段 | 差值 |
|---|---|---:|
| `q` vs `o`（旋转 vs 绝对方向） | V3 | **−1.46** |
| `mq` vs `mo` | V3 | **−1.55** |
| `oq` vs `o`（在方向上加旋转） | V3 | **−0.59** |
| `moq` vs `mo` | V3 | **−0.56** |
| QDF vs CDF（并行分支） | V1 | **−1.33** |
| QDT vs Cartesian（token 融合） | V2 | **−1.18** |
| LQA `mq` vs `mo` | V8 | **−1.50** |

七次独立比较、三种不同的接入位置（并行分支、token 融合、注意力），方向全部一致。

**但要区分两个命题**：
- **"相对旋转携带信息"——成立**。`q` 单独相对 V0 有 +2.01；去掉幅度通道后仍有 +2.24（V1）。
- **"四元数是表达它的更好方式"——不成立**。它携带的信息是绝对方向信息的有损子集，
  因此在方向已知时是冗余，加进去反而稀释通道（V3 两处独立验证：−0.59 / −0.56）。

### 2.2 真正有效的是"重新读取潜在 VCG"，最好的表示是幅度 + 绝对方向

冻结的 640 维嵌入之外，潜在 VCG 轨迹仍有大量未被利用的诊断信息：一条 18 万参数的
小分支就能带来 **+4.27 pp**。V3 的分解给出了这些信息的构成：

| 成分 | 单独贡献 | 边际贡献（在其他成分之上） |
|---|---:|---|
| 绝对方向 u_t | +3.47 | +0.87 至 **+2.91** |
| 幅度 r_t | +1.37 | +0.71 至 +0.83（稳定） |
| 相对旋转 q_t | +2.01 | **−0.59 至 −0.56**（有方向时为负） |

而 `mo`（r + u）**89.55 超过未分解的 Cartesian 参考 `cdf` 89.33**，差别集中在
**HYP（0.8119 vs 0.7984）**——心室肥大是电压判据，`mo` 有专门的幅度通道，`cdf` 的幅度
混在三个分量里。**显式几何分解优于直接喂 Cartesian 轨迹，且原因可解释。**

### 2.3 位姿/几何校正只值约 +0.5 pp，且 V5 与 V6 是同一件事

`pinv(A₀R)e = Rᵀpinv(A₀)e`（对原版伪逆、float64 验证到 5e-13）——**旋转导联几何等价于
旋转恢复出的 VCG**。因此 V6 的 sample-conditioned 模式与 V5 的位姿正则化是同一族函数，
两条独立实现给出几乎相同的数字（加惩罚后都是 **+0.50**）。

两个附带结论：
- **全局几何校正是干净的阴性**：3 个自由参数放开上限后只转 1.1°，AUROC −0.02。
  **原版导联矩阵 A₀ 对 PTB-XL 没有系统性偏差可校正。**
- **硬上限会被顶满，惩罚才让角度反映数据**：无约束时最大校正角 122.8°（已无几何意义），
  加测地惩罚后回到中位 10.4°，精度只从 +0.98 降到 +0.50。**可辩护的增益是 +0.5。**

### 2.4 相位分辨与标签注意力都没有增量

- **V4**：整拍池化（89.55）优于 QRS+T+整拍（89.46）与 QRS+T（89.23）。编码器本就在做
  掩码平均，显式分窗只是重新分配权重，并没有比均匀平均更好。
- **V8**：`label`（89.70）与 `shared`（89.73）打平，两者相对 `mean`（89.55）的 +0.15
  小于 seed 波动。**标签特异没有额外贡献。**
- 两者的可解释性输出一致指向：**QRS 段信息密度最高**（V4：12.9% 的采样点达到整拍 99.1%
  的效果；V8：25% 的注意力落在 12.9% 的时间上，密度 1.94），而 **STTC 稳定偏向 T 段**
  是唯一在 seed 间可复现的标签特异信号。

## 3. 与四元数无关、但对该 checkpoint 有普遍意义的发现

这些是复现过程中暴露的原版实现性质，对任何使用该 checkpoint 的工作都适用：

| 发现 | 出处 | 影响 |
|---|---|---|
| **只有 beat token 1 能进入嵌入** | V2 | `emb_struct` 就是它，GRU 也只从它展开；其余心拍的形态永远到不了 logits。V2 的天花板由此决定 |
| **GRU 展开长度取决于 batch 内最大心拍数** | V2 | 一条记录的嵌入会随它落在哪个 batch 而变。改为按记录自身心拍数展开，**V0 提升 0.40 pp** 且结果不再依赖 batch |
| **预训练表示完全没有旋转不变性** | V5 | 90° 旋转掉 20.4 pp，150° 退化到 52.27（接近随机） |
| **不变性只能靠训练时见到旋转** | V5 | 但在相同增强下，带位姿估计比不带好 0.7–3.3 pp，且角度越大优势越大 |
| **`beat_level_loss` 按心拍数而非元素数平均** | 预训练报告 | 该项梯度被放大约 384 倍，主导预训练；`recon` 从 10 万步起就不再改善 |
| **重建保真度与表示质量脱钩** | 预训练报告 | 遮挡导联 R² 仅 0.33、幅度只有真实的 54%，但 frozen probe 达到 85.27 |

## 4. 如果要写成论文，可以支撑的三条主张

1. **潜在 VCG 轨迹中存在大量未被 LVCG 嵌入利用的诊断信息**（+4.27 pp，冻结主干、
   18 万参数、7 次跨阶段复现）。
2. **把心向量显式分解为幅度与绝对方向，优于未分解的 Cartesian 表示**（89.55 vs 89.33），
   且优势可归因到具体标签（HYP，电压判据）。
3. **相对旋转（四元数）在该任务上是绝对方向的有损冗余**：单独有效（+2.01），
   与方向共存时为负（−0.56 至 −0.59）。这是一个**阴性但可复现、机制清楚**的结论，
   七次配对比较方向一致。

**不能支撑的**：任何形式的"四元数优于实值表示"；相位分辨或标签注意力的价值；
全局导联几何校正的价值。

## 5. 若要继续，优先级排序

1. **旋转鲁棒性深化（最高）**：V5 发现 `canon+augment` 在全部 7 个角度优于纯 `augment`
   （90° 差 3.28 pp）。**这是全线唯一一处四元数相关机制占优且尚未做实的线索。**
   补 2 个 seed（约 8 分钟）即可定论。若成立，四元数的价值应重新定位为**不变性而非精度**。
2. **把 `mo` 确立为新基线**：后续任何方法若不能超过 89.55，就不能声称几何建模上的进步。
3. **`mo` vs `cdf` 的 +0.22 需要确认**：补 seed 45/46（约 4 分钟），目前措辞保持"略优"。
4. **不建议做 V7**：方案要求只组合"已单独验证"的模块，而 q_A（global）阴性、
   q_card 不敌 CDF、conditioned q_A 与 V5 同源。若仍要做，必须如实定位为
   "V5 位姿 + V1 旋转特征的可加性检验"，而非"外部几何与内在动力学互补"。
5. **不建议进入 Tier 2**：所有阶段的 Tier 1 都未给出可归因的几何优势，
   放开 fine-tuning 只会让归因更困难（方案第 10 节的前提未满足）。

## 6. 工程与可复现性

- **198 个单元测试**覆盖四元数工具（附录 B 全部条目）、每个阶段的 V0 等价性、
  跨阶段的数值一致性（`mq` 与 V1 逐通道相同、V4 整拍 = V3、V8 `mean` = V3 至 1e-7）、
  以及两条支撑实现的数学恒等式（旋转与心拍分段可交换；旋转几何 = 旋转 VCG）。
- **每个阶段都有 V0 行**，且各自与锁定值吻合，因此所有比较都在同一管线内完成。
- **冻结特征缓存**让一个变体训练约 1 分钟；全线 V1–V8 共约 120 次运行。
- 结果、逐 epoch 曲线、诊断量（相位覆盖率、位姿角分位数、注意力占比）全部落盘。
